# Product Requirements Document (PRD)
**Project Name:** Капитал-шоу "Поле Чудес: Premium Edition"
**Mode:** Compact Mode (Hot-Seat Multiplayer)

## 1. Original Requirements
Создать игру "Капитал-шоу Поле Чудес" с упором на потрясающий визуал (премиальный дизайн, современный UI, микро-анимации, стеклянный морфизм). Основной приоритет — надежная архитектура без багов. Игра должна быть защищена от любых некорректных действий игрока (foolproof). **Формат игры:** только живые игроки в режиме Hot-Seat (за одним экраном, передача хода), 3 игрока в туре. Боты не используются.

## 2. Product Goals
1. **Premium Visual Experience:** Glassmorphism, мягкие тени, плавные микро-анимации.
2. **Rock-Solid State Management:** Строгий конечный автомат (State Machine), исключающий состояния гонки и невалидные переходы.
3. **Hot-Seat Multiplayer:** Удобный и понятный механизм передачи хода между 3 живыми игроками.

## 3. Use Cases (по Алистэру Коберну)

### UC1: Вращение барабана
*   **Primary Actor:** Активный игрок (Игрок N)
*   **Preconditions:** Состояние `WAITING_FOR_SPIN`. Ход Игрока N.
*   **Main Success Scenario:** Игрок нажимает "Вращать". Игра переходит в `SPINNING`. Барабан крутится, останавливается на секторе с очками. Переход в `WAITING_FOR_LETTER`.
*   **Extensions:**
    *   *Спам-клик:* Последующие клики игнорируются, кнопка блокируется.
    *   *Клик по буквам во время вращения:* Игнорируется (ввод заблокирован).

### UC2: Ввод буквы
*   **Primary Actor:** Активный игрок
*   **Preconditions:** Состояние `WAITING_FOR_LETTER`. Барабан остановился на очках.
*   **Main Success Scenario:** Игрок вводит согласную букву. Буква есть в слове. Открываются ячейки, начисляются очки. Игрок сохраняет ход и может снова вращать барабан.
*   **Extensions:**
    *   *Буквы нет в слове:* Передача хода следующему (UC4).
    *   *Ввод гласной:* Заблокировано.
    *   *Буква уже была названа:* Ввод игнорируется, UI показывает покачивание кнопки.
    *   *Ввод с другой раскладки (латиница):* Игнорируется.

### UC3: Назвать слово целиком
*   **Primary Actor:** Активный игрок
*   **Preconditions:** Игра ожидает вращения или ввода буквы.
*   **Main Success Scenario:** Игрок нажимает "Назвать слово". Открывается модальное окно. Игрок вводит слово верно. Присуждается победа в туре (UC11).
*   **Extensions:**
    *   *Введено неверное слово:* Игрок выбывает из игры (UC7).
    *   *Ввод пустой строки:* Кнопка подтверждения заблокирована.

### UC4: Передача хода (Hot-Seat)
*   **Primary Actor:** Система / Игроки
*   **Preconditions:** Игрок ошибся буквой, выпал сектор "Ноль" или "Банкрот".
*   **Main Success Scenario:** Система определяет следующего по кругу не выбывшего игрока. Показывается экран "Ход переходит к Игроку X". Ожидание клика "Начать ход" для предотвращения случайных действий.
*   **Extensions:**
    *   *Остался только один игрок:* Передачи хода не происходит, оставшийся игрок крутит барабан до победы.

### UC5: Сектор "Банкрот" (Б)
*   **Primary Actor:** Система
*   **Preconditions:** Барабан остановился на секторе "Б".
*   **Main Success Scenario:** Очки активного игрока сбрасываются до 0. Вызывается UC4 (Передача хода).
*   **Extensions:**
    *   *Очки уже равны нулю:* Очки остаются нулем, просто передается ход.

### UC6: Сектор "Ноль" (0)
*   **Primary Actor:** Система
*   **Preconditions:** Барабан остановился на секторе "0".
*   **Main Success Scenario:** Очки игрока сохраняются, но ход немедленно передается следующему (UC4).

### UC7: Выбывание игрока
*   **Primary Actor:** Активный игрок / Система
*   **Preconditions:** Игрок назвал неверное слово целиком (UC3) или взял Приз (UC8).
*   **Main Success Scenario:** Игрок помечается как `ELIMINATED`. Его UI затемняется. Ход переходит к следующему (UC4).
*   **Extensions:**
    *   *Выбывают 2 из 3 игроков:* Третий игрок автоматически продолжает игру в одиночку.
    *   *Третий игрок тоже называет слово неверно:* Game Over без победителя.

### UC8: Сектор "Приз" (П)
*   **Primary Actor:** Активный игрок
*   **Preconditions:** Барабан остановился на секторе "П".
*   **Main Success Scenario:** Открывается диалог: взять N очков (торг) или "Приз". Игрок выбирает "Приз". Игрок получает случайный приз, его очки сгорают, он покидает игру (UC7).
*   **Extensions:**
    *   *Игрок берет очки:* Начисляются очки, игрок продолжает ход (крутит барабан).
    *   *Спам кнопок в модалке:* Блокируется после первого клика.

### UC9: Сектор "Плюс" (+)
*   **Primary Actor:** Активный игрок
*   **Preconditions:** Барабан остановился на секторе "+".
*   **Main Success Scenario:** Состояние `WAITING_FOR_CELL_CLICK`. Игрок кликает по любой закрытой букве на табло. Буква открывается (все ее вхождения в слове). Очки не начисляются. Игрок продолжает ход.
*   **Extensions:**
    *   *Клик по уже открытой букве:* Игнорируется.

### UC10: Две шкатулки
*   **Primary Actor:** Активный игрок
*   **Preconditions:** Игрок угадывает 3 буквы подряд.
*   **Main Success Scenario:** Пауза в игре. Появляется модалка с двумя шкатулками. Игрок кликает на одну. В ней "Деньги" (начисляется бонус). Игра продолжается.
*   **Extensions:**
    *   *Выбрана пустая шкатулка:* Ничего не происходит, окно закрывается, игрок продолжает ход.
    *   *Закрытие модалки по Esc/backdrop:* Запрещено, обязателен выбор шкатулки.

### UC11: Победа в туре / финале
*   **Primary Actor:** Система
*   **Preconditions:** Слово полностью открыто на табло.
*   **Main Success Scenario:** Триггер `WIN_STATE`. Запускается конфетти, фанфары. Победивший игрок переходит в финал / супер-игру.
*   **Extensions:**
    *   *Анимации наслаиваются:* Прерываем все идущие анимации вращения/открытия, очищаем очередь таймаутов.

### UC12: Супер-игра
*   **Primary Actor:** Победитель финала
*   **Preconditions:** Игрок выиграл финал.
*   **Main Success Scenario:** Игрок соглашается. Загадывается 1 главное и 2 побочных слова. Игрок называет несколько букв. Дается таймер (60 сек). При успехе — тотальная победа.
*   **Extensions:**
    *   *Игрок отказывается:* Игра завершается, игрок уходит с текущими очками.
    *   *Таймер истек:* Поражение в супер-игре, но победа в основной сохраняется.

## 4. Requirement Analysis & Pool (Разбивка на инкременты)

### Инкремент 1: Core Hot-Seat & Basic Loop
*   [REQ-1.1] Базовая стейт-машина (Idle, Spin, Letter, Pass Turn).
*   [REQ-1.2] Поддержка 3 живых игроков (Hot-Seat): UI переключения игроков, передача хода при ошибке.
*   [REQ-1.3] Вращение барабана (визуал + логика) с базовыми секторами очков.
*   [REQ-1.4] Экранная клавиатура, табло со скрытым словом.
*   [REQ-1.5] Защита от спама и невалидного ввода (Extensions UC1, UC2).

### Инкремент 2: Special Sectors & Advanced Rules
*   [REQ-2.1] Секторы "Банкрот" и "Ноль".
*   [REQ-2.2] Сектор "Плюс" (открытие любой ячейки по клику).
*   [REQ-2.3] Сектор "Приз" (торг за очки или выбывание с призом).
*   [REQ-2.4] Возможность досрочно "Назвать слово". При ошибке — выбывание.

### Инкремент 3: Meta, Mini-games & Premium Polish
*   [REQ-3.1] Мини-игра "Две шкатулки" (при угадывании 3 букв).
*   [REQ-3.2] Режим "Супер-игра" для финалиста (с таймером).
*   [REQ-3.3] Premium UI / Glassmorphism полировка, продвинутые микро-анимации.
*   [REQ-3.4] Полноценный аудио-движок.
